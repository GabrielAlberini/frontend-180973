## Ejercicio 1
Calculadora de descuento Crear un formulario con un input numérico donde el usuario ingrese un precio. Al hacer submit, mostrar en un párrafo el precio original y el precio final con un 20% de descuento aplicado. Si el precio ingresado es 0 o negativo, mostrar un mensaje de error en rojo sin aplicar el descuento. 

## Ejercicio 2
Cambio de tema Crear una página con un título, un párrafo de texto cualquiera y un botón que diga "Modo oscuro". Al hacer click, cambiar el fondo de la página a negro y el texto a blanco, y cambiar el texto del botón a "Modo claro". Al volver a hacer click, revertir todo al estado original. 

## Ejercicio 3
Lista de tareas simple Crear un formulario con un input de texto y un botón "Agregar". Al hacer submit, tomar el valor del input y crear un nuevo elemento <li> dentro de un <ul> con ese texto. Si el input está vacío, mostrar un mensaje de advertencia y no agregar nada. Después de agregar una tarea, limpiar el input automáticamente.
