1 - Un componente es una función que retorna HTML
2 - Un componente no puede retornar más de un elemento HTML
3 - Existe una solución que se llama fragment, sirve para retornar un elemento padre, sin etiqueta
4 - El atributo "class" en React es "className"
5 - TODAS los elementos en React cierran
6 - TODOS los componentes comienzan en mayuscula porque sino React interpreta que se trata de una etiqueta html
7 - El renderizado condicional consta de aplicar una condición directamente en JSX
8 - Cuando el renderizado condicional tiene 2 opciones, se utiliza el operador ternario (condicion ? caso verdadero : caso de no éxito)
    Si el renderizado condicional solo tiene una resolución, se utiliza el operador AND (&&)
